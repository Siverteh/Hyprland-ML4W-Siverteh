# Independent Matrix rest renderer

2026-10-10 UTC. Replace the entire matrix-rest.py body after recording previous
source exposure. Earlier first-source comparison found shared helper fragments with
an old mini-calendar and imported ML4W welcome code. Even where boilerplate is
generic, do not certify uncertain ancestry; delete and author fresh from this
behavior/native terminal specification without old/upstream body consultation
while writing. Keep notices and make no legal clean-room claim.

The existing shell wrapper owns its Kitty window and toggle/focus behavior. Python
is presentation only: drifting columns of ASCII letters, digits and punctuation,
bright leading cell and fading trails, spacing two cells on wide terminals, one
on narrower outputs. Resize rebuilds column geometry. Target 10 frames/second,
never a hidden/background desktop service. No lock, sleep, power or auth action.

Use canonical published Nacre primary/secondary/onsurface/surface colors. Dark
surface tinted slightly toward primary, dimmed accent trails and foreground-tinted
heads preserve the preferred gentle nighttime effect. Role/math outputs remain
simple public data; no Matugen/Rofi/ML4W file dependency. Safe fixed green/dark
fallback if no valid canonical file. load_palette() stays the pure test interface.

Run only in a terminal. Save and restore original termios and terminal cursor,
colors/mouse modes/alternate screen on normal exit, signal or rendering exception.
After a 350ms startup grace, any key/mouse input exits; SIGTERM/SIGINT also exit.
No actual full-screen rest window during QA. Use deterministic fake RNG/frame/
terminal size, temp-home palette and an owned PTY subprocess for resize/output/
exit/cleanup. Fake-native tests cover the wrapper separately; do not kill any
existing user terminal or Matrix window to demonstrate toggle behavior.
