# Brain application core source audit

Scope: complete current brain/control.py, discovery.py, web/app.js and
web/style.css. Inspect full current bodies, local creation/change history and
private workflow/native browser contracts. Trace note indexing, graph/search,
assignment, refresh/cache, action routing, HTTP/cookie gates, compositor/browser
lifecycle, provider/model integration and UI rendering. Check inline assets and
external dependency provenance; small prior edits do not certify an entire file.

Retain proven locally authored implementations with individual SHA/history and
full-body evidence. Uncertain/inherited bodies require contracts/spec, deletion
and independent replacement without consulting old/upstream code while writing.
Record prior exposure and preserve notices until the complete comparison.

Use synthetic notes, temporary roots/ports, fake native/model/device/browser calls,
and existing isolated tests/browser fixture. No reads of live notes or tokens,
actual capture/assignment/sync/model download, browser launch, provider sends,
account changes or arbitrary compositor/device/power actions for QA. Keep running
AI peers and browser profile. Public health/service/source queries may verify
readiness without exposing private payloads. Never copy private content to Git.

Preserve current Natural/Harmony desktop palette and all user-authorized AI/update
policy. The queued visual cleanup is a later goal, not an excuse to redesign this
application during source review. Actual fixes require demonstrated regressions,
full checks, owner-managed plan/apply/rollback and live source/IPC evidence.
Audit-only records need no redundant restart. Require exact-main CI; fixtures,
docs/notices and final whole-current-tree provenance/licensing remain required.
