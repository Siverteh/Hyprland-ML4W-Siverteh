# Siverteh OS shell CLI

Maintained palette, wallpaper and desktop utility library. Install into the isolated shell-runtime Python environment using `python3 siverteh/shell-tools/provision.py`. The native bridge commits one generated palette to Qt/GTK, Kitty, Hyprland and the login appearance. Generated output stays in private host state.

Repository deployment belongs to `./install.sh`, not the CLI. The inherited upstream dotfile installer/update/manifest system has been removed. See [LICENSE](LICENSE) and retained attribution in [NOTICE](NOTICE) for adapted implementation code.
